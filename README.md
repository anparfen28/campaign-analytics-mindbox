# Рекламный аналитик Mindbox

Скилл для Claude Code. Отвечает на вопросы про рекламу ивентов Mindbox, связывая
три источника, которые сейчас никто не сводит вместе.

## Зачем

Цифры кампаний лежат в таблицах, а объяснения к ним — в комментариях Trello
и в доках по ссылкам. Никто их не сопоставляет, поэтому один и тот же канал
бывает «находкой» в одном комментарии и провалом по цифрам в другом, а решение
уходит в следующую кампанию по тому мнению, что прозвучало первым.

Скилл держит в голове историю 269 площадок, бенчмарки по годам и выводы коллег —
и отвечает по цифрам, с цитатами и ссылками на первоисточник.

## Что умеет

| Спрашиваешь | Получаешь |
|---|---|
| «Какие каналы взять на вебинар в октябре, бюджет миллион?» | подборку с историей по каждой площадке |
| «Разбери, как отработал Фоксфорд» | сшивку трёх источников, факт против плана, выводы коллег |
| «Что известно про Золотые пуши?» | досье: 15 размещений, динамика CPA, где не сработал |
| «Сколько денег на 50 S+?» | диапазон с допущениями, не одно число |
| «Как идёт кампания на август?» | стадию, зрелость данных, что уже видно |
| «Когда публиковать посты?» | эффект дня выхода относительно даты ивента |

Название ивента можно называть приблизительно — «Фокс», «июньский», «тот,
что с Яндексом». Если вариантов несколько, переспросит, а не угадает.

## Безопасность

**Только чтение.** Ни одной функции записи в Trello или Google Sheets в коде нет.
Единственное, куда скилл пишет, — своя локальная папка `knowledge/`.

Доступы у каждого свои и лежат вне репозитория: `config.json`, `.env` и токены
в `.gitignore`.

## Установка

Подробно — в [INSTALL.md](INSTALL.md). Коротко:

1. Положить папку в `~/.claude/skills/`
2. `python3 scripts/setup.py --trello` — ключ и токен Trello
3. `python3 scripts/setup.py --google client_secret.json` — доступ к таблицам
4. `python3 scripts/preflight.py` — проверка

Терминал не обязателен: всё это можно попросить сделать Claude в чате.

## Как устроено

```
SKILL.md          правила и порядок работы
references/       контекст, источники, сшивка, обратная связь, формат ответа
scripts/          выгрузка, чистка данных, вся арифметика
knowledge/        накопленные бенчмарки, досье площадок, правила
```

Граница простая: **считает всегда код, судит всегда модель**. Ни одна цифра
в ответе не появляется из головы — только из вывода скрипта.

## Обновление базового знания

```bash
python3 scripts/bootstrap.py
```

Пересчитывает бенчмарки и досье площадок из живых источников. Запускать раз
в месяц-полтора. Папку `knowledge/` при обновлении скилла не затирать.
