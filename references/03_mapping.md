# Сшивка: как понять, что это один и тот же ивент

Самая коварная часть работы. Один ивент называется по-разному во всех трёх источниках,
и наивное сопоставление по названию не просто промахивается — оно **уверенно находит
не то**.

## Почему по названию нельзя

Реальные пары, проверенные на ивентах 2026:

| Сводная | Карточка Trello | Вкладка посевов |
|---|---|---|
| Реклама по расчету | Промо: ивента **с Яндексом** 25.02 | Кампании SS |
| Новичок → ядро | Промо: ивент **Invisible, Азбука вкуса и SKMS** (21 мая) | Ивент SKMS |
| Ревью Полугодия | Промо: **ивент 18 июня** | Ивент Ревью полугодия |
| Вебинар Фоксфорд | Промо: **ивент CDP** 22 июля | Ивент Foxford - июль 2026 |
| Как обогнать бенчмарки | Промо: ивент **c исследованием** (апрель) | — |
| Вебинар **Mario Berlucci** | Промо: ивента **Марио Берлучи** \| 12.02 | Ивент Марио Берлучи |

По названию совпадает **один из семи**. В карточках Trello имена внутренние и
календарные («ивент 18 июня»), в сводной — публичные названия ивента, во вкладках —
третий вариант. Публичное название иногда лежит только в `desc` карточки, а иногда —
вообще только в комментарии: «Реклама по расчету» нашлась исключительно в реплике
от 19.01.2026.

Хуже того, фаззи-матч даёт **ложные срабатывания с высокой уверенностью**:
«Как обогнать бенчмарки» (ивент) склеивается с карточкой «Промо: бенчмарки рассылок» —
это другая, контентная кампания на шесть комментариев.

И отдельная ловушка: **«Фоксфорд» 2025 и «Ивент Foxford» 2026 — разные ивенты**,
которые делят 8 общих Telegram-каналов, потому что закупаются в одних местах.
Ни название, ни пересечение каналов сами по себе их не различают.

## Рабочий алгоритм

### Шаг 1. Кандидаты по дате

Дата ивента берётся из колонки B сводной. В названиях карточек Trello дата зашита
почти всегда — числом (`12.02`, `23.03`, `25.02`) или словом (`21 мая`, `18 июня`,
`22 июля`). Ищем среди карточек **только списков «Готово»**.

Даёт одного кандидата в 6 случаях из 7. Если день не указан, а только месяц
(«ивент c исследованием (апрель)») — падаем на матч по месяцу и году, кандидатов
станет больше.

### Шаг 2. Числовой отпечаток — обязательное подтверждение

Дата даёт кандидата, числа его **доказывают**. Собираем эталонные числа из таблиц
и проверяем, встречаются ли они в тексте комментариев карточки.

**Эталоны выбирать только те, которые люди произносят вслух:**

| Годится | Не годится |
|---|---|
| факт регистраций по вкладке | внутренний план по каналам (462) — его не цитируют |
| план из брифа карточки | суммы, которые никто не считает руками |
| % выполнения плана | точные копейки |
| % целевых S+ | |
| суммарный бюджет | |

**Допуски:** проценты — ±1 (округляют по-разному: 72,51% станет «72» у человека и
«73» у скрипта). Суммы — ±1%. Числа из прозы вытаскивать со склейкой разделителя
тысяч пробелом, иначе «2 700 руб.» распадётся на 2 и 700.

**Порог:** совпало два и более различимых эталона — связка доказана. Совпал один,
но он редкий и точный (например, трёхзначный факт регистраций) — связка вероятна,
пометь и продолжай. Ноль совпадений — **не связывай**, скажи человеку.

### Шаг 3. Что делать с расхождением названий

Если числа сошлись, а названия разные — **связывай и явно сообщай о расхождении**:
«связала по числам; в сводной ивент называется X, в Trello Y, во вкладке Z».
Это само по себе полезная информация.

Если числа не сошлись — не склеивай, даже если название совпадает идеально.

## Проверенный пример: Фоксфорд

```
Запрос: ивент «Вебинар Фоксфорд», 22.07.2026

Шаг 1 · вкладка «Ивент Foxford - июль 2026»: факт 335, план по каналам 462
Шаг 2 · кандидатов по дате 22.07 среди 40 карточек «Готово»: 1
        → «Промо: ивент CDP 22 июля»
Шаг 3 · сверка чисел из комментариев:
        факт 335 ✓ · план из брифа 300 ✓ · выполнение 119% ✓ · целевых S+ 88% ✓
        → связка подтверждена, 4 из 5
```

Карточка: https://trello.com/c/eZ2palPm, список «Готово 2026», 45 комментариев,
финальный разбор Дины Коновой от 24.07.2026.

⚠️ Первая версия этой проверки брала эталонами «план 462» и «выполнение 73%» и дала
1 из 3 — то есть **отвергла бы правильную карточку**. План 462 никто не произносит,
а 73% — результат моего округления против написанного человеком «72». Отсюда правила
про допуски и выбор эталонов выше.

## Сшивка вкладки посевов с флайтом во «Все каналы»

Отдельная задача. Работает **пересечение нормализованных ссылок `t.me/…`**, но
метрика — не похожесть, а **доля каналов флайта, найденных во вкладке**:

```
вкладка «Ивент Foxford - июль 2026» (72 канала):
  2026 · Ивент Foxford      22 из 22 = 100%   ← верный
  2025 · Фоксфорд            9 из 15 =  60%
  2025 · Конференция 2025    9 из 33 =  27%
```

По Жаккару правильный ответ даёт всего 0,31 и не отличается уверенно. По покрытию —
100% против 60%, разрыв чёткий. **Обязательно фильтровать по году**, иначе два
Фоксфорда склеятся.

## Хранение

Готовые связки складывать в `knowledge/events.jsonl`, чтобы не пересчитывать:

```json
{"event": "Вебинар Фоксфорд", "date": "2026-07-22",
 "trello": {"id": "...", "url": "https://trello.com/c/eZ2palPm", "name": "Промо: ивент CDP 22 июля"},
 "tab": {"gid": 2118781143, "title": "Ивент Foxford - июль 2026"},
 "flight": "Ивент Foxford",
 "confirmed_by": ["факт 335", "план 300", "119%", "88%"],
 "name_mismatch": true}
```
