# Формат ответа

**Правило номер один: коротко.** Человек задал вопрос — он хочет ответ, а не отчёт
о проделанной работе. Всё, что не влезло, он спросит сам. Длинный ответ читается
как хаос, даже если каждая строка в нём верна.

Никогда не пересказывай, что ты делал: «я прочитала три источника, сшила их,
посчитала» — это шум. Показывай результат.

## Структура по умолчанию — четыре блока, не больше

```
**Оценка.** Одно-два предложения: как я оцениваю кампанию и на чём это основано.

Три-четыре ключевые цифры — по строке каждая, не таблицей на 20 строк.

**Что улучшить:**
1. …
2. …
3. …

Источник: ссылка на карточку · при необходимости одна цитата
```

Максимум — **15 строк**. Не влезает — значит ты отвечаешь не на тот вопрос.

Пункты «что улучшить» — конкретные и выполнимые. Не «улучшить подбор каналов»,
а «снять 108 900 ₽ с Марзаганова: первое размещение, 1 целевой S+».

## Под разные вопросы — разный объём

| Вопрос | Что отдаём |
|---|---|
| «Как идёт кампания» | стадия + зрелость данных + 3 цифры + 2–3 пункта. **Не больше 10 строк.** |
| «Разбери кампанию» | структура по умолчанию, 15 строк |
| «Какие каналы брать» | 3 строки текста + **HTML-таблица** с подсветкой |
| «Что с каналом X» | 3–5 строк: тренд, последнее размещение, вердикт брать/не брать |
| «Сколько денег на N S+» | диапазон в 3 строках + допущения одной строкой |
| «Сравни два ивента» | таблица на 5–6 строк + один вывод |

## Когда HTML, а когда чат

**HTML** — когда данных много и важно увидеть их глазами: подборка каналов,
рейтинг площадок, разбор кампании для пересылки команде. Генерируется
`scripts/report.py`, открывается в браузере.

Смысл HTML не в красоте, а в **цветовой разметке**: плохое видно сразу, без чтения.
Красным — то, что стоит убрать; жёлтым — под вопросом; зелёным — ядро, которое
работает. Человек смотрит три секунды и понимает картину.

**Чат** — всё остальное. Короткий ответ в чате лучше длинного HTML.

## Чего не делать

- Не вываливать таблицу на 22 строки, когда вопрос был «как дела»
- Не пересказывать методологию — она в справочниках
- Не повторять цифру в тексте, если она уже есть в таблице
- Не писать «важно отметить», «стоит подчеркнуть» и прочие связки без содержания
- Не выдавать незрелую цифру за итоговую: пост вышел вчера — «ожидается около»
- Не извиняться за отсутствие данных, просто сказать одной строкой, чего нет

## Обязательное в любом формате

**Оценка идёт первой.** Не цифры, не методология — сначала суждение.

**Каждая цифра проверяема.** Ссылка на карточку Trello, цитата с автором и датой.
Но цитат — одна-две, а не все найденные.

**Стадия названа явно**, если кампания не завершена: «кампания идёт, до ивента
9 дней, цифры неполные».
